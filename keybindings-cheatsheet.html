Строки и отступы

C-oНовая строка под текущей, в конец строки + RET с отступом
M-oНовая строка над текущей, в начало строки + RET
C-aВ начало строки → к отступу
C-|В начало буфера
C-}В конец буфера
M-AВыделить весь буфер
C-_ C-zОтменить (undo-fu)
M-_Повторить отменённое (redo)
M-↑ ↓ ← →Перетащить строку / выделение

Поиск и переходы

C-sПоиск построчно (consult-line)
M-iСовпадения по символу под курсором
M-IImenu — функции/заголовки файла
M-g gПерейти к строке
M-RET s rripgrep по проекту
M-RET s ggit grep по репозиторию
C-x C-\Перейти к метке в mark-ring
M-yВставить из kill-ring с просмотром

Буферы, окна, файлы

C-x C-kЗакрыть текущий буфер
C-x eОчистить буфер

C-x C-jDired для файла/каталога под курсором
C-x !Shell
